# 📘 Pokédex Web App

## 🔰 Project Overview

The Pokédex Web App is an interactive web application that allows users to explore and learn about different Pokémon. Users can browse a list of Pokémon, search for specific ones, and view detailed information such as types, abilities, and stats.

---

## 🎯 Objective

* [ ] Integrate a public API using JavaScript (fetch)
* [ ] Dynamically display data on a webpage
* [ ] Implement search, filtering, and sorting using array HOFs
* [ ] Build a responsive and visually appealing UI
